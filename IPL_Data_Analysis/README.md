# IPL Data Analysis

This project performs data analysis on IPL match data using Python, Pandas, and Matplotlib.

## Topics Covered

* Data loading and inspection
* Data cleaning
* Pandas data manipulation
* GroupBy operations
* Sorting and filtering
* Top scorers analysis
* Match winner and toss winner analysis
* Data visualization using Matplotlib

## Technologies Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Dataset

IPL match dataset containing information about matches, teams, toss results, scores, winners, top scorers, and bowling figures.

## Project

The analysis explores IPL match data and extracts useful insights such as top scorers, match winners, toss winners, and scoring patterns.
